# Task27
Reading and Writing Excel Data using Pandas

Description

This project demonstrates how to read Excel files using Python Pandas, inspect data, perform basic data cleaning and transformations, and export the processed data into a new Excel file.

Tools Used

- Python
- Pandas
- Jupyter Notebook
- OpenPyXL

Tasks Performed

1. Created sample Excel data.
2. Loaded Excel data using "read_excel()".
3. Inspected data using "head()", "info()" and "describe()".
4. Checked and removed missing values using "dropna()".
5. Added a new column for data transformation.
6. Exported the processed data using "to_excel()".

Output

Successfully created a processed Excel file.

Conclusion

Learned how to read, inspect, clean, transform and write Excel data using Pandas.
